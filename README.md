# Инструменты для заказчиков дизайна

Два браузерных инструмента для тех, кто заказывает упаковку и печать. Открываются файлом, работают без интернета, ничего не сохраняют и никуда не отправляют: ни форм, ни аналитики, ни бэкенда.

**Живая версия:** https://design.kovtun.studio/tools/

## Что внутри

### [Конструктор брифа на упаковку](brief-packaging.html)

25 вопросов о продукте, канале продаж, покупателе, конкурентах и технических ограничениях. Часть вопросов появляется только для вашего случая: редизайн, маркетплейсы, розничные сети. На выходе — готовый текст брифа, который можно скопировать или сохранить в PDF.

Зачем: разрозненные материалы на старте — самая частая причина, по которой срок проекта уезжает на неделю. Заполненный бриф эту неделю возвращает.

### [Чек-лист приёмки макета в печать](print-check.html)

35 пунктов в шести блоках: геометрия и вылеты, цвет, изображения, шрифты, обязательные элементы упаковки, передача файлов. Критичные пункты отмечены отдельно. На выходе — список замечаний, который отправляется подрядчику одним сообщением.

Зачем: ошибку на этом этапе дизайнер исправляет за час, ту же ошибку на тираже оплачивает заказчик.

## Как пользоваться

Скачайте репозиторий и откройте `index.html` в браузере. Или зайдите на https://design.kovtun.studio/tools/ — там то же самое.

Никакой сборки, зависимостей и установки: три HTML-файла, весь код внутри них.

## Как встроить к себе

Файлы самодостаточные. Положите их на свой сайт, поменяйте цвета в блоке `:root` в начале каждого файла, замените ссылки в подвале. Правки чек-листа под требования вашей типографии делаются в массиве `DATA` в `print-check.html` — структура читается без знания JavaScript.

Требования конкретной типографии всегда главнее любого общего чек-листа. Этот список — отправная точка для разговора с производством, а не замена его техтребованиям.
